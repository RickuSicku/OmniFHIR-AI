# Contributing to OmniFHIR AI

Thank you for your interest in contributing to OmniFHIR AI! We welcome contributions of all forms, including bug reports, feature requests, documentation improvements, and code changes.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/RickuSicku/OmniFHIR-AI.git`
3. Create a branch for your changes: `git checkout -b feature/my-new-feature`
4. Make your changes and write tests if applicable.
5. Ensure your code follows the styling and quality guidelines.

## Pull Request Process

1. Keep your PRs small and focused on a single change.
2. Update the README.md with details of changes to the interface, if applicable.
3. Make sure to fill out the pull request template.
4. Once your PR is reviewed and approved, it will be merged into the `main` branch.
